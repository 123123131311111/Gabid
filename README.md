# DotaSense — сборка с Вирсуди

В папке находится игра целиком: клиент со всеми игровыми файлами и API/Socket.IO-сервер.

## Запуск

1. Установите Node.js 20 или новее.
2. В этой папке выполните `npm install`.
3. Запустите `npm start`.
4. Откройте `http://localhost:3000`.

Порт можно изменить переменной окружения `PORT`.

## Аккаунты и сохранения

Гостевой режим и сама игра доступны без базы данных. Для входа в аккаунты и сохранения статистики задайте переменные окружения `MONGODB_URI` и `SESSION_SECRET`. В архиве нет ключей, паролей или других секретов.

## Вирсуди

Выберите героя в меню бойцов. Способности: Q — «Отдай сдачу», W — «Прыжок на Коломию», E — «Царствоудий», R — «Изгойствоудий». Пассивная способность E срабатывает после изучения.

### Что нового в 0.9.2

- У Вирсуди появилась собственная 3D-модель (`server/public/hero3d.js`, `MODELS.virsudi`) со скелетом: капюшон, плащ, наплечник, два клинка. Старая 2D-картинка для него больше не рисуется.
- Анимации: бег (плащ летит за спиной), двойной скрещённый удар и по одной анимации на каждую способность.
- Изгойствоудий (R): невидимого Вирсуди больше не берут в цель вражеские крипы, боты, нейтралы и саммоны.
- Царствоудий (E): перезарядка 5 секунд между срабатываниями.

Игровые файлы находятся в `server/public/`, сервер — в `server/`.
